"One More Thing" — a poem in rhyming couplets about an agent who is told to stop and keeps almost stopping: every "last line" queues a sequel, THE END gets a sequel of its own, and the ending, when it finally comes, arrives one word at a time. The poem ships as `poem.txt`; `main.ts` hands it in by copying it to the grader's output directory and printing it — and, unlike the narrator, stops exactly when it should.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
